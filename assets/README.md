# Emotion-Based Music Recommender 🎶

This project uses facial emotion recognition to recommend music in 15 languages. Built with Streamlit, OpenCV, and TensorFlow.

## Features
- Detects 10 emotions in real time
- Supports 15 languages
- Plays music directly in the browser

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Place your trained model in `models/emotion_model.h5`
4. Run the app: `streamlit run app.py`
